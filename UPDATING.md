# Idiot Cup: annual update

The master record is `data/idiot_cup.json`. The website (`docs/`) is built from it.
The old Excel workbook (`source/idiot_cup_v3_thru2025.xlsx`) was the seed and is no longer updated.

## What to give Claude after each trip

1. Attendance list (everyone who went)
2. Ryder Cup: both captains, both rosters, every match by day (format, pairings, points)
3. Belt: champions, gross score, net score, any playoff note
4. Calcutta: owners, winning bid, total pot, number of teams
5. CTP winners by day (with fractional splits)
6. Trip info: destination, final-day course, dates, international or not

## What Claude does

1. Adds one trip object to the end of `trips` in `data/idiot_cup.json`, using the 2026 entry as the template.
   RC individual points are computed from the matches, not typed in.
2. Updates `meta.updated`.
3. Runs `py tools/build.py`. This runs `tools/validate.py` first and refuses to build if anything fails
   (unknown player, belt champ not marked as attending, match points that do not add up, and so on).
4. Opens `docs/index.html` and checks the new Year in Review, trip page, and leaderboards.
5. Commits and pushes. GitHub Pages republishes in about a minute.

New players: add the name to `players.core` before adding the trip.

## Where things live

| Path | What |
|---|---|
| `data/idiot_cup.json` | Master record, every trip since 2003 |
| `docs/` | The website (GitHub Pages serves this folder) |
| `docs/data.js` | Generated by `tools/build.py`; do not edit by hand |
| `tools/validate.py` | Consistency checks |
| `tools/seed_from_workbook.py` | One-time import from the 2025 workbook (already run; rerunning overwrites the JSON) |
| `source/` | Original workbook and old dashboard, for reference |
